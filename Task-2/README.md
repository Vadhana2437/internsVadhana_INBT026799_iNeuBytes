## 1. Introduction
NovaMart is a front-end e-commerce demonstration website developed using HTML, CSS, and JavaScript. It allows users to browse products, search for items, filter categories, and manage a shopping cart.

## 2. Objectives
- Display products with names, prices, and categories.
- Implement product search and category filtering.
- Show product details.
- Add and remove products from the cart.
- Update product quantities and calculate totals.
- Provide a responsive user interface.

## 3. Technologies Used
- HTML5 – Website structure.
- CSS3 – Styling and responsive design.
- JavaScript – Search, filters, product details, and cart functionality.
- Browser Local Storage – Preserve cart contents across page refreshes.

## 4. Features
- Product catalog with eight sample products.
- Product search and category filtering.
- Price sorting and product details popup.
- Add to cart and remove from cart.
- Increase and decrease product quantities.
- Automatic subtotal and total calculation.
- Cart persistence using Local Storage.
- Responsive desktop and mobile layout.
- Demo checkout message without real payment processing.

## 7. Limitations and Future Enhancements
The project is a front-end demonstration. It does not include a backend, database-based order management, user authentication, or real payment processing. Future enhancements could include these features.
